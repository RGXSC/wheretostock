# Archive

Work that is no longer on the main path but is kept whole, because it was right
for what it was built for and may be wanted again.

| file | what it is |
|---|---|
| `simulate-five-boutiques.html` | The fast-forward deck as it was until November 2026: **five boutiques** (Paris, Tokyo, New York, Shanghai, London), a 650-piece board with its own forecast and its own season. Complete and working — open it like any other page of the suite. |
| `SIMULATE-SPEC-five-boutiques.md` | The spec that explains that deck: the season slide beat by beat, the colours, the flexible-capacity engine, and the study of how typical its season is. |

**Why it was replaced.** The deck now plays the game's own board — the same five
bags, Paris and Tokyo, the same forecast and the same season — so that a room
which has just played can put its own result beside every figure on the slides
(`../SIMULATE-SPEC.md`, "The board is the game's"). The five-boutique board made
the same argument on a wider network, with numbers nobody in the room had
produced.

Nothing here is checked by `check-drift.mjs`.
